## Decisions

### D0. Contracts kept

1. The body gate is unchanged: `--chunk` windows the same `output` the gate allows, so a body still needs `--include-bodies --ack-data-egress`, and without them the windows are over the summary. `--out` outside the vault, `--format jsonl` only, read-only, id-sorted: unchanged.
2. Every record's `meta` gains `topics` (the list, `[]` when absent), `authority_tier`, `volatility` and `source_url` (each `null` when absent), chunked or not, so one record shape serves both modes. `last_verified` stays.
3. Token windows are not built, as the issue decided; windows are character counts over the `output` string.

### D1. The three flags

- `--chunk <chars>` and `--overlap <chars>` (default 0): both parsed as integers; `chunk` below 1, `overlap` below 0 or at least `chunk`, or a non-integer, is thrown from `buildExport` and printed as `export refused: ...` with exit 1. With `chunk` set, each record becomes one record per window: window `i` starts at `i * (chunk - overlap)` and holds `output.slice(start, start + chunk)`; windows continue while `start` is less than the length, and an empty `output` gives one empty window; each is `{ input, output: <window>, meta: { ...meta, chunk: { index, start, end, total } } }` with `end` the start plus the window's length and `total` the window count, in id order then index order. A reader reassembles an entry by concatenating window 0 and, for each later window, its text from offset `overlap`.
- `--fresh-only`: drops an entry with `status: superseded` and an entry for which `staleness({ volatility, last_verified }, schema, now)` is truthy; `null` (an unknown volatility) and `false` keep it. `now` is `new Date(opts.now || today)`, as `listStale` converts it, since `staleness` subtracts a `Date`; `opts.now` is `--now`; the schema is `loadSchema(repoRoot, { vaultPath })`, so the vault's taxonomy extensions are merged.
- `--min-authority <tier>`: a value outside `schema.taxonomy.authority_tier` is thrown and printed as `export refused: ...`; a source whose `authority_tier` sits after the floor in that list is dropped; a row with no tier and a non-source type pass.

The filters apply before chunking and before the scope's own rules. `run` passes `chunk`, `overlap`, `freshOnly: !!args['fresh-only']`, `minAuthority` and `now` to `buildExport`; `fresh-only` joins `BOOL`.

### D3. Tests

In `test/export.test.mjs`:

1. The default export's records carry `meta.topics` (an array), `meta.authority_tier`, `meta.volatility` and `meta.source_url` keys; a hand-written source with `authority_tier: 'primary'` exported under `--scope source` carries them with its values and `source_url`.
2. Round trip: a note captured with `captureEntry` passing `body` as the 26 letters (`captureEntry` builds the body as `# Long\n\n`, the letters and a trailing newline), exported with `scope: ['note'], includeBodies: true, ackDataEgress: true, chunk: 10, overlap: 3`, gives windows whose `meta.chunk.total` equals their count, `start` values `0, 7, 14, ...`, `end` the start plus the window length, and whose reassembly (window 0, then each later window from offset 3) equals the body `readEntry` returns; the same export without bodies windows the summary.
3. `run({ vault, chunk: '5', overlap: '5' })` and `run({ vault, chunk: '0' })` return 1 after printing `export refused`, and `run({ vault, chunk: '5', overlap: '2' })` returns 0.
4. `--fresh-only`: a source with `volatility: 'fast'` verified 2026-01-01, a superseded note, and a fresh note verified on `now`; `buildExport(dir, { scope: ['source', 'note'], freshOnly: true, now: '2026-11-02' })` (the string converted inside) omits the first two and keeps the third; without the flag all three export.
5. `--min-authority secondary`: a `tertiary` source dropped, a `primary` source, an untiered source and an answered question kept under `scope: ['source', 'question']`; `minAuthority: 'gold'` throws `/min-authority/`.
6. The existing export tests pass with the widened `meta`, since they read its keys one by one, and the one `deepEqual` compares a record with its own JSON round trip, which `null` and `[]` values survive.
